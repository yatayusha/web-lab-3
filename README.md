# web-lab-3

**Логика:**

- Реализация движений вверх, влево, вправо, вниз

`[4, 4, 4, 4] -> [16, 0, 0, 0]` (движение влево) (+32 очка - +8, +8, +16)

`[16, 16, 2, 2] -> [32, 4, 0, 0]` (движение влево) (+36 очков - +32, + 4)

- Реализация проверки окончания игры (нет возможных движений)
  
- Появление 1-2 новых плиток с значениями 2/4 на случайных пустых клетках

- Отображение текущего счета пользователя
  
- Реализация отмены хода (в случае завершения игры отменить ход нельзя)
  
- Сохранение состояния игры, сохранения лидерборда


**Особенности реализации:**

1) Все четыре направления сводятся к сдвигу влево: вправо и вниз ряд разворачивается, вверх и вниз столбец читается как ряд
2) Плитки как отдельные элементы, таблица не перерисовывается
3) Состояние игры сохраняется в localStorage
4) Управление зависит от экрана: широком окне (ноут или комп) ход делают стрелки клавиатуры, на узком и на сенсорном экране (телефон) появляются четыре кнопки и работает свайп по полю
